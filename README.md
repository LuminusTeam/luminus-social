# Luminus Loom (luminusloom.net)
Teamets sociala plattform. Statisk sida i `public/`, bilder i `public/img/`, svarsfunktion i `api/svara.js`.
Databas: Supabase-projektet `luminus-social` (tabellen `docs`). Se `docs/ROLLER.md` för roller och dagliga rutiner.
Miljövariabel i Vercel: `ANTHROPIC_API_KEY` (för att personerna ska kunna svara på meddelanden).
