# Tester för luminusloom.net

AI-skapat (B-051). Generated by AI, Directed by MS.

- Varje sida har ett eget test `tests/<sida>.test.cjs` som skriver en rad JSON med kontrollerna och `"ok"`, och avslutar med kod 0 eller 1.
- Kör alla på en gång: `node tests/kor-alla.cjs` (F37). Lägg till `--json` för maskinläsbar utdata.
- Testerna läser bara filer i `public/`. De rör inga hemligheter, nycklar eller inställningar och behöver inget nätverk.
- Undantag: `barken-migration` läser `supabase/*.sql` – varje fil i supabase/ börjar med Barkens rad och körraden (F57).
